# 4팀 변수 판정 테스트 — 기준선부터 H1·H2까지 (2026-11-10 실행)

## 0. 판정 규칙 (결과 보기 전에 고정)
| 무엇을 | 도구 | 규칙 |
|---|---|---|
| 쓸모(예측에 도움 되나) | XGBoost 누적 학습 단계별 IC | 직전 단계보다 **평균 IC↑** 그리고 **11개 검증 연도 중 6년 이상** 연평균 IC↑ → OK. 기준선은 판정 없이 유지 |
| 방향(가설대로인가) | Fama-MacBeth, 5분위 표 | 부호가 가설 방향 & \|t\|≥2 "어느 정도 지지", ≥3 "확실하게 지지" / 반대 부호 & \|t\|≥2 "반대 방향으로 유의" / 그 외 "확인하지 못함" |
| 참고 | 증가분 t | 매달 (이번 단계 IC − 직전 단계 IC)의 평균 ÷ 표준오차. 판정에는 안 씀 |

## 2. 변수 (모두 t월 말까지 알 수 있는 정보, 정답 target = t+1월 수익률)
| 묶음 | 변수 | 정의 |
|---|---|---|
| 기준선 | 베타 | 최근 60개월(최소 24) 초과수익률 vs 시장(직전 달 시총 가중) 초과수익률 기울기 |
| | 규모 | ln(t월 말 시총) |
| | 가치 | 1/PBR (PBR≤0은 결측) |
| 통제 | 단기 반전 | t월 수익률 |
| | 모멘텀 | t−11~t−1월 누적수익률(11개월 중 8개월 이상) |
| 보강(옛 "유지 후보") | 고유변동성 | 최근 24개월(최소 12) 시장모형 잔차 표준편차 |
| | 주식 발행 | ln(주식 수 ÷ 12개월 전 주식 수) |
| 수급 H1 | 개인 순매수 비율 | t월 개인 순매수 ÷ t−1월 말 시총 |
| 수급 H2 | 외국인 순매수 비율 | t월 외국인 순매수 ÷ t−1월 말 시총 |

모델 입력: 매달 단면 순위(0~1), 빈칸 0.5 + 결측 표시 열.

## 3. 학습 방식 (누적 학습식)
- 검증 연도 Y = 2011…2021. 학습 = 2001-01 ~ (Y−1)-11 행 (그 행의 정답이 Y−1년 12월 수익률까지라 Y년 1월에 이미 알 수 있음) → Y년 12개월 예측. 매년 1월 1번 재학습.
- XGBoost 설정 고정: 300그루, 깊이 4, 학습률 0.05, subsample 0.8, seed 42. 타깃은 다음 달 수익률의 그달 순위.
- IC = 매달 예측 점수와 실제 다음 달 수익률의 Spearman 순위상관. 검증 131개월(2011-01~2021-11; 2021-12의 정답은 2022-01이라 test).

## 5. 결론
1. 기준선(0.051) → 통제(0.077) → 보강(0.088) → 수급(0.092) 모두 규칙 통과. 누수 점검 IC −0.001.
2. 보강 묶음은 고유변동성이 전부(11/11), 주식 발행은 단독 추가 시 NO.
3. **H1 반대**: 개인이 많이 산 종목이 다음 달 오히려 높다(FM t +3.1, 수급 표 t +3.1). 반전·모멘텀·규모 등을 같이 넣어도 남음. 계획서의 반대 가능성 "유동성 공급"과 같은 방향.
4. **H2 확인 못함**: 2011~21은 유의하지 않고, 2002~21 전체는 오히려 반대(−2.7).
5. 수급 변수는 XGBoost 쓸모 기준으로는 통과(+0.004, 9/11) — 방향이 가설과 반대여도 예측에는 도움이 됨. 개인 단독이 11/11로 더 강함.
6. 예측력은 중소형주에 집중(상위 100 IC 0.023).

## 6. 우리 질문 (11/16 교수님께)
- 개인 순매수가 + 인 것은 개인이 떨어진 종목을 사는(역추세) 습관 때문인가, 진짜 유동성 공급 보상인가? → 단기 반전을 통제해도 남는다는 결과를 어떻게 해석할지.
- XGBoost 증가분 t(예: 수급 +0.0043, t 2.7)를 보조 근거로 써도 되는지.
- 고유변동성은 통과, 주식 발행은 단독 NO → 보강 묶음을 고유변동성만으로 줄일지.
- 대형주에서 IC가 낮은 문제: 보고서에 전체·대형 IC를 같이 내도 되는지.
