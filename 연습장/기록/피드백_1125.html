④ 효과가 안 나올 때는 변수를 잘못 만든 건지, 모델에 반영이 안 된 건지 먼저 가려라(모든 팀 공통).
⑤ 발표 후 팀 논의: 모델은 XGBoost 유지, 정형 피처 추가(업종 기준 모멘텀·변동성 등)를 목표가 상향 때처럼 판정 절차로 검증.

1. 우리 팀 발표와 질의응답

우리가 말한 것: ESG 실패 후 테마 여러 개를 같은 기준으로 판정 → 목표가 상향만 통과, 키워드가 임베딩보다 정밀도가 높아 키워드 사용, 정형+뉴스 합친 데이터 결측률 약 28%, 누수 점검 후 거래 관련 변수 수정, 팀 코드로 재현해 보니 비슷하게 나옴, 통제 후 효과 +0.5%.

교수님 질문·말씀그 자리 답정확한 답·보완 (기록 확인 후)
효과가 얼마냐통제 후 0.5% 상승정형 9개 통제 후 다음 달 월 +0.51%p (t 2.5), 2016–21 +0.47%p (t 1.9)
지난달 뉴스로 다음 달을 보는 거면 효과가 누적되어야 한다 (추정)다른 테마와 달리 효과가 그나마 오래 가는 테마좋은 소식은 다음 달까지 남고 나쁜 소식은 그달에 끝나는 경향(테마 판정 결과)
변수 10개냐 / 다른 팀도 IC가 0.1 근처로 비슷하다 (추정)네정형 9개 + 목표가 상향 1개. 다른 팀과 IC 수준이 비슷하다는 말씀은 "아무 변수 10개로도 이 정도는 나온다"는 뉘앙스일 수 있음 → 우리 변수가 더해주는 몫을 따로 보여줄 필요
기사가 평균 몇 개쯤 있나 (한 달에)전체 5만 건? 한 달씩은 따로 못 봄정정 필요: 5만은 변수 파일의 행 수(49,985). 실제로는 상위 200 종목 기사 한 달 평균 약 4,800건, 그중 목표가 상향 기사 월 평균 약 51건(약 26종목). 2001년은 월 4건, 2015년은 96건으로 시기별 차이가 큼
하향 기사는 없냐, 봤냐상향 테마라 하향은 따로 생각 못 함정정 필요: 테마 스크리닝 때 목표가 하향도 판정했음 → "그달에 반영되고 끝"이라 제외. 하향 기사는 월 평균 약 30건(약 17종목)
상향−하향을 같이 넣으면 음의 방향도 자연스럽게 반영할 수 있지 않나-할 일: 순지표(상향 − 하향)를 같은 판정 기준으로 확인
키워드가 놓친 비율이 뭐냐 / '목표주가 상향'과 비슷한 다른 표현을 못 찾는다는 거냐정밀도는 사람이 확인했고, 놓친 비율(재현율)은 아직 못 잼맞음. 예: "목표가 9만원으로 올려"처럼 키워드에 없는 표현. 놓친 기사는 0으로 들어가므로 효과는 과소 추정 쪽 → 할 일: 키워드에 안 걸린 기사에서 표본을 뽑아 재현율 측정

2. 교수님 공통 말씀 (모든 팀)

주제내용

판을 뒤집지 말 것지금 하는 것에서 하이퍼파라미터 튜닝이나 정의 다듬기 정도로 적당히 개선해 보라. 시간을 많이 잡아먹는 새 시도보다 있는 것을 마무리
교수님이 직접 돌려볼 수 있게데이터를 2025년까지(6~7년 더) 늘려서 돌린다고 할 때 무엇을 해야 하는지, 실행 방법을 과정 어딘가에 적어두면 교수님이 그대로 실행해 보겠다. 데이터가 없는 경우가 아니면 확장을 고려해서 만들 것
한계점 적기예: "월별 데이터를 쓰기 때문에 ○○는 안 된다" 같은 한계를 적어두면 읽으면서 해보겠다 (추정)
비슷한 다른 테스트중요한 가정은 비슷한 다른 테스트로 한 번 더 확인하면 좋겠다 (추정)

3. 다른 팀 발표에서 참고할 점

  • 누수 발견 사례: 2019년 5월 기준 예측에 2019년 전체 수익이 반영된 것을 발견하고 고침 → 우리도 같은 종류의 누수가 없는지(연간 값이 월별에 들어가는지) 예원 점검표에 추가
  • 모델 비교: 정형만 있을 땐 XGBoost가 높았는데 뉴스를 넣으니 MLP가 높게 나옴 → 우리 비교 결과(비선형 모델 비슷, 선형만 낮음)와 같은 맥락
  • 노이즈 변수와 비교: 무작위 노이즈 변수를 넣은 것과 비교해 뉴스 변수가 노이즈보다 나은지 확인 → 우리 목표가 변수에도 해볼 만함
  • 뉴스 신호가 며칠 안에 사라짐: 일별 검증으로 전환하는 팀 있음. 우리는 다음 달 예측이라 "다음 달까지 남는 테마만 고른다"는 우리 방식이 이 문제에 대한 답
  • 뉴스-종목 매칭률이 낮음: 빅카인즈 기관 칼럼으로는 종목의 95%가 뉴스 없음 → 제목·본문 매칭으로 전환. 우리는 이미 제목 매칭 + 기간표로 처리함
  • 투자자별 수급에 모멘텀 적용(교수님 지난주 제안): 약간 오름, 특정 연도(2017–18)에 편차가 큼
  • 정형 피처 추가: 거래량 규모, 외국인 보유량을 넣었더니 성능이 꽤 오름

4. 발표 후 팀 논의

주제내용
재현팀 코드 재현은 계속 진행
모델 비교 (영섭)XGBoost, LightGBM, 랜덤포레스트, 신경망, 릿지 5개 비교 → 비선형 모델은 IC 0.091~0.094로 비슷, 선형(릿지)만 낮음. 다만 목표가 상향의 IC 기여는 XGBoost·신경망에서만 나오고 LightGBM·랜덤포레스트에서는 안 나옴. 우리 테마를 입증하는 모델은 XGBoost이므로 XGBoost 유지. 다음 브리핑에서 "다 비교해 봤고 IC는 비슷, 선형보다 확실히 좋다"로 보고. 모델 비교 PDF는 영섭이 정리해서 공유
아쉬운 점ESG·논란형 같은 이전 테마도 다른 모델로 비교했으면 좋았겠지만, 지나간 일이라 이번엔 XGBoost로 감
정형 피처 추가주어진 기본 자료(시가총액, 주식 수, 종가 수익률, 종목명·코드)로 만들 수 있는 피처 검토. 아이디어: 업종 기준으로 계산한 모멘텀·변동성 (업종별로 계산한 변수가 효과가 좋다는 연구가 많음). 기존 변수와 같이 써도 됨. 목표가 상향 때처럼 판정 기준을 먼저 정하고 결과를 돌려볼 것
데이터 추가 수집주어진 데이터로 안 되면 어떤 피처가 효과가 있었고 무엇을 긁어와야 하는지 목록을 정리 (발언자 확인 필요)
