최종 변수와 모델 결정

작성: 위영섭 · 근거: 피처추가검토_1125.pdf, 모델 비교(out_yw/model_compare*.csv), 기간 안정성(out_yw/feat_half.csv)
결론
① 모델은 XGBoost로 간다. 비선형 모델끼리 성능은 비슷하지만, 우리 가설 변수(목표가 상향)의 기여가 나오는 모델이 XGBoost이고 재현도 가장 쉽다.
② 최종 변수 12개: 정형 9개 + 목표가 상향 + 고유변동성 + 6개월 모멘텀. 앞뒤 기간(2011–16, 2017–21) 모두에서 IC를 올린 것만 남겼다.
③ 외부 데이터(업종, 거래량, 외국인 보유, 재무제표)는 이 환경에서 직접 받을 수 없어서 팀원 PC에서 정식 경로로 받고, 같은 판정 기준으로 추가 여부를 정한다.

1. 외부 데이터 직접 수집 시도 결과

경로결과대안
KRX (pykrx)접속 허용 후 시도 → 응답이 "LOGOUT". KRX가 로그인한 회원에게만 데이터를 주도록 바뀜팀원이 로그인해서 CSV 다운로드 (안내 문서 준비)
OpenDART접속은 됨. 인증키가 주소 안에 들어가는 방식이라 이 환경에서 키를 안전하게 쓸 수 없음팀원이 키 발급 후 본인 PC에서 스크립트 실행 (스크립트 준비)
네이버 금융가격·거래량은 받아지지만 상장폐지 종목이 빠지고, 페이지 대량 수집은 권한 검사에서 막힘(이용약관상 자동 수집 제한)사용하지 않음

2. 모델 결정: XGBoost

판단 기준결과유리한 모델
성능비선형 4개 평균 IC 0.091~0.094로 비슷, 차이는 통계적으로 의미 없음(t ≤ 1.2). 선형(릿지)만 확실히 낮음(t −2.1)비선형 전부
우리 가설 변수목표가 상향을 넣었을 때 IC가 오른 모델: XGBoost(+0.0011, 7/11년), 신경망(+0.0016, 6/11년). LightGBM·랜덤포레스트는 안 오름XGBoost, 신경망
새 피처 반영고유변동성·6개월 모멘텀을 넣으면 XGBoost 0.0964(t 3.2), LightGBM 0.0973(t 3.8), 랜덤포레스트 0.0970(t 2.0), 신경망 0.0947(t 0.9)나무 계열
재현성seed 고정 시 같은 결과, 실행 9초. 신경망은 seed에 따라 흔들리고 실행이 10배 느림, 랜덤포레스트도 15배 느림XGBoost, LightGBM
이미 해 둔 것팀 코드(04_model), 모든 판정, 재현 계획이 XGBoost 기준XGBoost

정리: 세 조건(가설 변수 기여, 새 피처 반영, 재현성)을 모두 만족하는 모델은 XGBoost뿐이다. 다른 모델은 보고서에 "모델을 바꿔도 IC 수준은 비슷했다"는 강건성 확인으로 넣는다.
