# 뉴스 테마 판정 결과 (팀 공유용, 11/20)

## 한 줄
ESG처럼 뉴스 테마 5개를 긍정·부정으로 나눠 판정 → **긍정 쪽 실적·애널리스트·수주 3개가 기준 통과.** 다만 실적·애널리스트도 효과가 2015년까지에 몰려 있고 최근엔 약함. **'실적' 테마를 다음에 깊게 파 볼 1순위로.**

## 뭘 했나
- 테마: 실적 / 애널리스트 의견 / 주주환원·자금조달 / 신용등급 / 사업 계약 (제목 키워드로 긍정·부정)
- 데이터: 뉴스 129만 건 + 정형 데이터셋(예원), 상위 200, 2001–2021
- 이달 말까지 기사로 신호 → 다음 달 수익률
- 판정 기준(미리 정함): 다음 달 차이 또는 통제 9개 FM에서 |t| ≥ 2 + 2016–21에도 같은 방향

## 결과
| 테마 | 판정 | 다음 달 효과 (통제 후) | 기간별 (2001–10 / 2011–15 / 2016–21) | XGBoost (11년 중 오른 해) |
|---|---|---|---|---|
| 실적 호재 | **지지** | +0.57%p (t 2.9) | +0.85 / +0.33 / +0.05 | 8년 |

| 수주·공급계약 | 지지(불안정) | +0.41%p (t 2.1) | +0.68 / −0.81 / +0.67 | 4년 (오히려 나빠짐) |
| 주주환원·자금조달 | 빼기 | - | - | 5년 |
| 신용등급 | 빼기(부정은 표본 부족) | - | - | 7년 |
| 부정 기사들 (실적 악재, 목표가 하향 등) | 모두 빼기 | 그달에 크게 반영되고 끝남 | | |

- 좋은 소식(실적 호재, 목표가 상향)만 다음 달까지 조금 남고, 나쁜 소식은 그달에 끝남
- 단, 최근(2016–21)엔 실적·애널리스트 단순 효과가 거의 0 → 감성 점수와 같은 모양
- 9개 신호를 동시에 봐서 t 2 근처(수주 t 2.1)는 우연일 수 있음
