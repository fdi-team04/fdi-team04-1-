# 뉴스 테마 빠른 스크리닝 계획 (11/19)

## 목적
ESG처럼 테마를 하나씩 정해서 몇 주씩 파면 시간이 모자람. 11/18 피드백대로 **한 명(영섭)이 여러 테마를 같은 기준으로 한 번에 걸러서**, 통과한 테마만 팀이 깊게 파기.

## 분류 방법: 키워드 vs 임베딩 (교수님 질문 정리)
- 교수님 질문: "기사 분류를 키워드 조합으로 하나, FinBERT 임베딩(문장 의미를 숫자로 바꾼 것)으로 하나? 고른 이유가 있어야 한다."
- 임베딩은 문장 전체 의미를 보니까, '메리츠화재'(회사 이름)와 '공장 화재'(사고)를 키워드처럼 헷갈리지 않음.
- **지금 단계(테마 고르기)에서는 키워드로 충분.** 효과가 있는 테마인지 빨리 보는 게 목적이라, 약간 틀린 기사가 섞여도 큰 효과라면 보임.
- **테마가 통과하면** 그때 임베딩 분류와 키워드 규칙을 사람 정답으로 비교해서 더 정확한 쪽을 고르고, 그 이유를 기록.

## 테마 후보 12개 (theme_rules.py)
| 테마 | 기대 방향 | 왜 '다음 달까지' 효과가 남을 수 있나 |
|---|---|---|
| 실적_호재 / 실적_악재 | + / − | 실적 발표 뒤 몇 달간 같은 방향으로 더 움직이는 현상(실적 발표 후 표류)이 많은 나라에서 알려짐 |
| 목표가_상향 / 목표가_하향 | + / − | 애널리스트 의견 변경 뒤 주가가 천천히 따라간다는 연구가 있음 |
| 자사주 | + | 회사가 "우리 주식 싸다"는 신호. 매입 발표 뒤 장기간 초과수익 연구가 있음 |
| 증자_메자닌 (유상증자·CB·BW) | − | 비쌀 때 찍어 판다(정형 '주식 발행' 변수와 같은 논리), 물량 부담이 이어짐 |
| 지분매각_블록딜 | − | 대주주 매도 = 내부자가 비싸다고 봄, 남은 물량(오버행) 부담 |
| 수주_공급계약 | + | 금액이 실적에 반영되기까지 시간이 걸림 |
| 배당_확대 | + | 이익이 지속된다는 신호 |
| 신용등급_하향 / 상향 | − / + | 등급 변경 뒤 주가가 천천히 반영된다는 연구가 있음 |
| 인수합병 | ? | 방향 가설 없음 (양쪽 검정) |

## 빠른 판정 기준 (결과 보기 전에 정함)
| 관문 | 기준 | 왜 |
|---|---|---|
| ① 데이터 | 테마 기사가 있는 종목-월 300개 이상, 2016–21에도 30개 이상 | 너무 드물면 판단 불가 |
| ② 단순 차이 | 다음 달 수익률(있음−없음)이 기대 방향, \|t\| ≥ 2 | 효과가 있나 |
| ③ 통제 후 | 다른 변수 9개 넣은 FM에서 기대 방향, \|t\| ≥ 2 | 큰 회사·오른 회사라서 생긴 착시인지 걸러냄. **테마를 12개 보니 우연 통과를 막는 핵심 관문** |
| ④ 최근 유지 | 2016–21 FM 계수가 기대 방향 | 감성처럼 2016년에 끊긴 효과는 지금 못 씀 |

- **②③④ 모두 통과 → '파 보기'**: 제목 50건 사람 확인(정밀도 80%), 키워드 vs 임베딩 비교, XGBoost에 넣어 IC가 11년 중 6년 이상 오르는지
- **③만 통과 → '보류'**: 기간·정의를 한 번만 점검
- **③ 실패 → '빼기'**: 기록하고 종료
- 같은 달 차이는 참고로만 봄 (이미 지난 수익)

## 주의
- 12개를 동시에 보면 효과가 없어도 t 2를 우연히 넘는 테마가 하나쯤 나올 수 있음 → 그래서 ③(통제 후)과 ④(최근 유지)를 같이 통과해야 함
- 키워드 사전(v0)은 결과를 보고 바꾸지 않음. 바꾸면 버전을 올리고 이유를 기록

3. 분석: `python yw_run/theme_screen_yw.py theme_monthly.csv full` → `out_yw/theme_screen_full/theme_screen.csv` (테마별 판정 자동)
