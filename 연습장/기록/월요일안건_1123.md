# 11/23(월) 브리핑 안건 (결과 반영판, 30분)

**목표: '목표가 상향'을 최종 뉴스 후보로 확정하고, 수요일까지 할 일을 나눈다.**

## 주말 결과 (미리 공유)
| 확인 | 결과 |
|---|---|
| 테마 5개 판정 | 실적 호재·목표가 상향·수주 통과, 나머지 빼기 |
| 50건 사람 확인 | 목표가 상향 **통과**(정밀도 94~100%, 일치 94%) / 실적 호재 **미달**(54~72%, 일치 74%) |
| 실적 키워드 v1 재판정 | 전망·예고 기사 빼니 2016–21 효과가 뒤집힘 → **보류(최근 소멸)** |
| 논조(감성 점수) | 실적·목표가 모두 효과 없음 → '기사 있음/없음'만 사용 |
| 실적·목표가 겹침 | 1/3만 겹침, 같이 넣어도 목표가 유지(t 2.4) |
| 수주 | 기간마다 방향이 뒤집히고 모델 IC 하락 → 제외 |
