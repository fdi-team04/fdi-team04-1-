# 정형 피처 추가 판정 기준 (11/25, 결과 보기 전에 작성)

데이터: v2 이전 정형 데이터(out_yw/features.parquet와 같은 원자료) + pykrx PBR·BPS·투자자 순매수 + CD91 금리. 기간 2001–2021.
기준 모델: 정형 9개 + 목표가 상향(현재 모델).

## 판정 단계
- A1 (FM): 정형 9개 통제 Fama-MacBeth, 2001–2021, |t| ≥ 2, 부호가 이론 방향과 같음 (방향이 정해지지 않은 피처는 양쪽 허용)
- A2 (최근): 2016–2021 FM 계수 부호가 A1과 같음
- B (XGBoost): 현재 모델 + 피처 → 평균 IC 상승 + 11년 중 6년 이상 연평균 IC 상승
- C (모델 강건성): 비선형 4개(XGBoost, LightGBM, 랜덤포레스트, 신경망) 중 3개 이상에서 평균 IC 상승
- 판정: A1·A2·B·C 모두 = 채택 / B·C만 = 모델 보조 후보 / A만 = 설명 변수 / 나머지 = 제외
- B를 통과한 피처만 C를 돌림(계산 시간). 마지막에 채택 피처를 한꺼번에 넣은 모델을 5개 모델로 비교
