# 주말 과업 최종본 (11/21, 팀원 정리표 + 영섭 계획 합침)

## 영섭
1. 50건 판정 합산: 아영·예원 두 사람 일치율, 갈린 번호 → 합의 → 정밀도(맞음 비율) 계산
2. 테마 변수 파일 만들기: 실적 호재·목표가 상향의 종목×월 '기사 있음/없음 + 개수' (논조는 안 넣음). **50건 결과 나온 뒤** 확정(v0 유지 또는 v1 수정)
3. 시도한 가설 전체 집계표: 감성, ESG, 논란형 2개, 테마 5개(9개 신호), 논조 — 각각 기준·결과·판정 (여러 번 시도했다는 걸 숨기지 않기 위해). 수주·공급계약은 이미 '불안정, 모델 IC 하락'으로 판정 → 기록만
4. 최근 약화 확인: 2016–21 연도별 효과, 상위 200 안에서 큰·작은 종목 비교 (2021년까지 데이터로만)
5. 교수님께 할 질문: 2022년 예측 방식(재학습 가능 여부), 2022년 뉴스도 써도 되는지, 키워드 vs 임베딩 선택 근거로 충분한지
6. 월요일 안건 진행

## 이안
1. 환경 고정(패키지 버전, 난수) + 01~06 한 번에 실행
2. 테마 변수 넣고 빼서 XGBoost IC 비교 (2011–21 검증 기간, 전체 코스피 모델). 상위 200 밖은 뉴스 없음 → 0 + '뉴스 대상 여부' 표시. 통과 기준: 평균 IC 상승 + 11년 중 6년 이상
3. **키워드 vs 임베딩 비교** (교수님 질문): 아영·예원 50건 정답으로 두 방법 정확도 비교
4. SHAP 변수 중요도·방향 정리 (6장: '가설 판정에 방향이 필요했다'로)
5. prediction.csv 코드 뼈대 + 2021년을 가짜 test로 리허설
6. 2022년 예측에 뉴스 변수를 쓰려면 2022년 기사 수집이 필요 → 매크로 수집 방식으로 가능한지 확인

## 예원
1. **50건 × 2개(실적, 목표가) 판정 — 아영과 각자 따로, 일요일까지** (최우선)
2. 최종 정형 데이터셋 완성 (주식 발행 포함, 결측 처리: 지금 모델과 같은 방식 = 월별 순위, 결측 0.5 + 결측 표시)
3. 정형 + 테마 변수 합치기 (종목코드·월). 뉴스 월은 '그달 마지막 거래일 전 기사'로 이미 배정돼 있으니 **추가로 밀지 말 것**, 수익률은 다음 달(target)
4. 합친 데이터 미래 정보 누수 점검
5. 변수별 이론 근거 표 + 데이터 사전 + 계획서에 중간 결정 기록(80% 기준 근거, ESG 규칙 수정, 논란형 종료, 테마 판정 기준·결과, 논조 미사용)

## 아영
1. **50건 × 2개(실적, 목표가) 판정 — 예원과 각자 따로, 일요일까지** (최우선)
2. 뉴스 변수 결측 처리 기준 정리 (상위 200 밖 = 뉴스 대상 아님 → 0 + 표시, 중립값 의미) → 이안·예원과 같은 기준으로 맞추기
3. 뉴스 출처·수집일·정리 이력표 (4,719건 복구, 16.6% 제거 근거)
4. 슬라이드 숫자·문구 점검
(ESG 새 기사 100건 뽑기는 보류: ESG는 '효과 없음'으로 빠진 테마라 지금은 필요 없음)

## 언제 하나 (순서가 걸린 일 정리)
| 시점 | 할 일 | 왜 이때 |
|---|---|---|
| **주말 (일요일까지)** | 아영·예원 50건 판정(최우선) / 이안 환경 고정·01~06·임베딩 비교 방법 준비 / 예원 정형 데이터셋 완성 / 아영 결측 기준 / 영섭 집계표·최근 약화·질문·**수요일 슬라이드 뼈대** | 다른 일에 안 걸리는 것들 |
| **월 브리핑** | 50건 정밀도 → 실적·목표가 최종 후보 결정 | 50건 결과가 있어야 결정 가능 |
| **월 이후** | 영섭 테마 변수 파일 확정 → 예원 정형+테마 합치기·누수 점검 → 이안 IC 비교·임베딩 비교 실행 | 키워드가 v0인지 v1인지 정해져야 시작 가능 |
| **화~수** | 예원 이론 근거 표·데이터 사전·계획서 기록 / 이안 prediction 리허설 / 아영 이력표·슬라이드 점검 | 수요일 발표와 보고서용 |
