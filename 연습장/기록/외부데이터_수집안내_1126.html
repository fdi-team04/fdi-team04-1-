외부 데이터 수집 업무 안내

KRX(예원) · OpenDART(아영) · 받은 뒤 판정(영섭) · 11/30 브리핑 전까지
한 줄 요약
KRX는 이제 로그인해야 데이터를 주고, DART는 본인 인증키가 필요해서 각자 PC에서 받는다. 양이 많으니 1순위(업종 분류, 22개 파일)부터 받고, 원본 그대로 드라이브 '외부데이터' 폴더에 올리면 영섭이 피처를 만들어 판정한다. 가공은 하지 않아도 된다.

0. 시작 전에 (각자 10분)

누구할 일확인
예원① data.krx.co.kr 회원가입·로그인 ② VS Code 터미널에서 pykrx 1분 시험:
pip install pykrx
python -c "from pykrx import stock; print(stock.get_market_ohlcv('20150130', market='KOSPI').head())"		표가 나오면 → pykrx로 받기 (영섭이 스크립트 줌)
에러·빈 값 → 아래 수동 다운로드
아영① opendart.fss.or.kr 회원가입 → 인증키 신청 ② pip install OpenDartReader pandas인증키 메일 수신

1. KRX 수동 다운로드 (예원)

사이트 개편으로 메뉴 이름이 조금 다를 수 있다. 화면에서 조회일자를 바꾸고 → 조회 → 다운로드(CSV)를 반복하는 방식이다.

순위받을 것화면과 조건파일 수만들 피처
1업종 분류주식 → 업종분류 현황. 시장 KOSPI, 조회일 = 매년 12월 마지막 거래일 (2000~2020)21개 (약 30분)업종 모멘텀, 잔차 모멘텀, 업종 대비 변동성
2월간 거래량·거래대금주식 → 전종목 등락률 (기간 조회). 시작일 = 그달 첫 거래일, 종료일 = 그달 마지막 거래일 → 기간 합계 거래량·거래대금이 나옴 (2001.01~2021.12)252개 (월별)회전율, 거래량 급증, 아미후드(월 단위 근사)
3외국인 보유량주식 → 외국인 보유량(전종목). 조회일 = 매월 마지막 거래일252개외국인 지분율 변화
양 조절: 2·3순위는 각 252번이라 혼자 하면 4~8시간이다. 1순위만 먼저 끝내고 톡방에 알리기. 2·3순위는 기간을 나눠서(예: 2001–2010 예원, 2011–2021 다른 팀원) 하거나, 1순위 결과를 보고 할지 정한다.

파일 규칙

  • 이름: krx_업종_2014.csv, krx_등락률_201503.csv, krx_외국인_201503.csv (조회한 연도·월)
  • 열이나 행을 지우지 말고 원본 그대로 드라이브 외부데이터/KRX/에 올리기
  • 받은 날짜와 파일 수를 뉴스 정리 이력표에 한 줄 추가

완료 확인: ☐ 업종 21개 파일 · 각 파일에 종목코드·종목명·업종명 열이 있음 · ☐ (2순위) 252개 · ☐ (3순위) 252개 · ☐ 이력표 기록

2. OpenDART 재무제표 (아영)

  1. 종목 목록 만들기: 예원 정형 데이터의 Stock_Code 열을 중복 없이 codes.csv로 저장 (열 이름 code, 약 1,000개)
  2. 깃의 연습장/data_fetch/dart_fetch.py를 같은 폴더에 두기
  3. VS Code 터미널(PowerShell)에서 키를 환경변수로 넣고 실행:
    $env:DART_KEY="발급받은키"
    python dart_fetch.py codes.csv
  4. 1~2시간 걸림. 50종목마다 dart_finstate.csv에 중간 저장됨 (중간에 꺼져도 다시 실행 가능하게 하려면 영섭에게 말하기)
  5. 결과 dart_finstate.csv를 드라이브 외부데이터/DART/에 올리기
받는 항목만들 피처주의
매출액, 매출원가, 매출총이익, 자산총계수익성 (매출총이익 / 자산) — Novy-Marx (2013)DART는 2015 사업연도부터만 있음. 12월 결산 사업보고서는 다음 해 3월 말 공시 → 다음 해 4월부터 사용 (available_month 칸)
자본총계, 당기순이익ROE — Hou, Xue & Zhang (2015)
영업활동현금흐름발생액 (순이익 − 영업현금흐름) / 자산 — Sloan (1996)
키 보안: 인증키는 본인 PC 환경변수에만. 코드 파일, 깃, 톡방, 드라이브에 쓰지 않기. 스크립트는 이 저장소 환경에서 실행해 보지 못했으므로, 에러가 나면 메시지를 캡처해서 영섭에게 보내기.

완료 확인: ☐ dart_finstate.csv 행 수 ≈ 종목 수 × 7년 · ☐ 매출액·자산총계 칸이 절반 이상 채워짐 · ☐ 이력표 기록

3. 받은 뒤 (영섭)

  1. 피처 계산식과 판정 기준을 먼저 git에 올림 (결과 보기 전)
  2. 미래 정보 규칙 적용: 업종은 전년 12월 말 값, 거래·외국인은 그달 말 값, 재무제표는 공시 후(다음 해 4월)부터
  3. 4단계 판정 + 앞뒤 기간(2011–16 / 2017–21) 안정성 → 통과한 것만 13번째 이후 변수로
  4. DART 피처는 2015년 이후만 값이 있어 학습 기간이 짧음 → 한계로 기록
