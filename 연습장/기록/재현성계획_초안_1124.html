3. 실행 순서

  1. 예원: 합친 input 최종본 저장 → 파일명·행 수·sha256을 이 문서 2장에 적기
  2. 이안: docker compose run --rm pipeline (01~06) 실행 → 실행 날짜, 패키지 버전, 출력 IC를 남기기
  3. 이안: 정형 9개 모델과 목표가 추가 모델을 각각 돌려 1장 숫자 1~3과 비교
  4. 같은 설정으로 한 번 더 돌려 두 번 결과가 같은지 확인 (seed 고정 확인)
  5. 아영: 1장 기준값과 팀 코드 결과를 나란히 놓고 숫자 점검. 허용 차이를 넘으면 4장 표에 원인 적기
