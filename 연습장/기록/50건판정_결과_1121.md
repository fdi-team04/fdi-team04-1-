# 실적·목표가 테마 50건 사람 확인 결과 (11/21, 월요일 안건 ②)

판정자 두 명(아영·예원)이 같은 50건을 각자 따로 판정. A = 이름 표시 없는 파일, B = 이름 표시한 파일. 기사 제목은 깃에 올리지 않음.

## 키워드 v1 (news/theme_rules.py, v0은 theme_rules_v0.py)
- '실적 개선' 키워드 제외 (대부분 전망·증권사 의견)
- '사상 최대'는 실적·매출·영업이익·이익·흑자 단어가 같이 있을 때만
- 제외 패턴: 전망·기대·예상·예고·예약·목표(목표가는 제외 안 함)·될 것·이어진·지속·내년·하반기·수혜·하향·↓·감소·적어·부진·과징금
- 같은 50건에 적용(참고용, 같은 표본으로 다시 잰 값): 31건 유지, 정밀도 **87% ~ 97%**, 두 사람 모두 '맞음'인 27건은 하나도 안 빠짐

## 실적 v1 재판정 (11/21, 미리 정한 규칙대로 한 번만)
| | v0 | v1 |
|---|---|---|
| 실적 호재 기사 (건) | 13,031 | 10,550 |
| 실적 호재 종목-월 | 6,011 | 4,288 |
| 다음 달 차이 | +0.50%p (t 2.3) | +0.40%p (t 1.8) |
| FM (통제 9개) | +0.57%p (t 2.9) | +0.51%p (t 2.4) |
| 기간별 2001–10 / 2011–15 / 2016–21 | +0.85* / +0.33 / +0.05 | +0.78* / +0.18 / **−0.07** |
| XGBoost IC (오른 해) | 0.0242 (8/11) | 0.0245 (7/11, t 1.5) |
| 판정 | 지지 | **보류(최근 소멸)** |

- 전망·예고 기사를 빼니 효과가 2001–10에 몰리고 2016–21엔 방향이 뒤집힘 → 미리 정한 규칙상 '보류(최근 소멸)'. 모델 반영 후보에서 제외.
- 해석: v0의 최근 효과 일부는 '실적 개선 … 목표가' 같은 증권사 전망 기사에서 나왔을 수 있음 → 그 정보는 '목표가 상향' 테마가 더 정확히 잡음
- XGBoost는 7/11년 올랐지만(2016–21도 6년 중 5년), 판정 규칙상 보류 테마는 모델 후보가 아님 → 이안 전체 모델 실험에서 참고로만 같이 확인
- 목표가 상향(정밀도 94~100%, FM t 2.7, 2016–21 FM t 1.8)이 **유일한 최종 후보**
- v1 새 50건 판정은 실적이 보류라 급하지 않음 (실적을 다시 살릴 때만 필요)
