# 목표가 상향을 전체 모델에 넣으면 IC가 오르나 (11/23, 영섭+Claude 사전 실험)

- 기준: 정형 9개 변수 XGBoost (step3 4단계와 같은 설정, 2011–2021 매년 1월 재학습, 전체 코스피)
- 비교: 기준 + tp_up(목표가 상향 있음 1/없음 0) + news_missing(전년 말 시총 상위 200 밖 = 1)
- 뉴스 파일: out/목표가상향_변수_합치기용.csv (전년 말 상위 200 기준, 월 이동 없음)
- 코드: yw_run/tp_fullmodel_yw.py / 결과: out_yw/tp_fullmodel.csv, tp_fullmodel_by_year.csv
- 통과 기준(미리 정함): 평균 IC 상승 + 11년 중 6년 이상

| 모델 | 전체 평균 IC | 기준 대비 | 오른 해 | 2016–21 오른 해 | 상위 200 안 IC 차이 | 판정 |
|---|---|---|---|---|---|---|
| 기준 (정형 9개) | 0.0905 | - | - | - | - | - |
| **+ 목표가 상향** | **0.0916** | **+0.0010 (t 1.4)** | **7/11** | **5/6** | **+0.0046 (t 2.0)** | **통과** |
| + 실적 호재 v1 (참고) | 0.0905 | −0.0001 | 4/11 | 3/6 | +0.0033 (t 1.6) | 미통과 |
| + 미수집 표시만 (대조) | 0.0905 | −0.0001 | 5/11 | 4/6 | +0.0005 (t 0.3) | 미통과 |

## 해석
- 목표가 상향을 넣으면 전체 IC가 0.0905 → 0.0916, 11년 중 7년(최근 6년 중 5년) 올라 **미리 정한 기준 통과**
- 뉴스는 상위 200 종목에만 있어서 전체 IC 증가는 작지만, **뉴스가 있는 상위 200 안에서는 +0.0046 (t 2.0)**로 뚜렷함
- '미수집 표시'만 넣으면 변화 없음 → 개선은 표시 칸이 아니라 목표가 상향 정보에서 나옴
- 실적 호재 v1은 개선 없음 → 보류 판정과 일치
