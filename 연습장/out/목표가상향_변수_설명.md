# 목표가 상향 뉴스 변수 (11/22 개정)

## 합칠 때는 이 파일: `목표가상향_변수_합치기용.csv` (11/22 밤 다시 고침)
- 행: **전년 12월 말 시가총액 상위 200 종목**의 그해 1~12월 (정형 데이터 market_cap 기준, 그해가 시작되기 전에 알 수 있는 정보)
- 이전 버전은 '그해 기사가 1건이라도 있는 종목'으로 정해서 1월 행이 12월 기사에 따라 정해지는 미래 정보 문제가 있었음(아영 지적) → 고침
- 그달 기사가 0건이어도 행이 있음 (tp_up = 0, news_missing = 0)
- 이 기준으로 바꿔도 결과 같음: 통제 9개 FM +0.51%p (t 2.5), 2016–21 +0.47%p (t 1.9)

## 합치는 법 (아영 결측 기준과 같음)
1. 정형 데이터에 **month·code 기준 왼쪽 합치기** (정형 데이터 행은 그대로 두고 뉴스 칸만 붙이기)
2. 이 파일에 **없는** 정형 행 = 전년 말 상위 200 밖 → `news_missing = 1`, `tp_up = 0`, 건수 칸 = 0
3. 월은 **추가로 밀지 않음** (뉴스 월 = 그달 마지막 거래일 전 기사). 예측 대상은 다음 달 수익률(target)
4. 건수는 순위로 바꾸지 않고 원래 값 그대로. 논조는 쓰지 않음
5. 평균 같은 통계가 필요하면 학습(train) 기간 안에서만 계산

| 칸 | 뜻 |
|---|---|
| news_missing | 1 = 전년 말 상위 200 밖(뉴스 변수 없음), 0 = 상위 200 |
| tp_up | **본 변수**: 그달 목표가 상향 기사 있음 1 / 없음 0 (키워드 v0, 정밀도 100%) |
| n_tp_up | 목표가 상향 기사 수 (참고) |
| n_news | 그달 그 회사 기사 수 전체 (참고) |
| n_tp_down | 목표가 하향 기사 수 (참고, 판정은 빼기) |
| n_earn_up_v1 | 실적 호재 기사 수, 키워드 v1 (참고, 판정은 보류) |

`목표가상향_변수_종목월.csv`(이전 파일)는 기사가 있는 달만 있어서, 합칠 때 쓰면 '수집했지만 기사 0건'과 '미수집'이 구분되지 않음 → 쓰지 말 것
