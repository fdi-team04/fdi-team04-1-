# 목표가상향_변수_종목월.csv (11/21)
- 행: 종목코드 × 월 (2001-01 ~ 2021-12), 그해 시총 상위 200 중 기사가 수집된 종목-월만 있음
- 월 배정: 그달 마지막 거래일 **전**에 나온 기사 = 그달 (마지막 거래일 당일·이후 기사는 다음 달). → 정형 데이터의 같은 월에 그대로 붙이고 **추가로 밀지 말 것**. 예측 대상은 다음 달 수익률(target)
| 칸 | 뜻 |
|---|---|
| n_news | 그달 그 회사 기사 수 (전체) |
| n_tp_up | 목표가 상향 기사 수 (키워드 v0, 정밀도 94~100%) |
| tp_up | 목표가 상향 기사 있음(1)/없음(0) ← **본 변수** |
| n_tp_down | 목표가 하향 기사 수 (참고, 판정은 빼기) |
| n_earn_up_v1 | 실적 호재 기사 수, 키워드 v1 (참고, 판정은 보류) |
- 이 파일에 없는 종목-월(상위 200 밖, 기사 미수집): 뉴스 변수 0 + '뉴스 대상 아님' 표시 (결측 처리 기준은 아영 정리 따름)
- 만든 곳: 영섭 PC theme_monthly.csv(theme_rules.py v1) → 연습장/out/
