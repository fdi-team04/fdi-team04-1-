# tables/ : 저장소에 올리는 작은 표

기사 원문이 들어 있지 않은 표만 둔다. `data/`와 달리 Git에 올린다.

| 파일 | 내용 | 만드는 곳 |
|---|---|---|
| `news_monthly.csv` | 종목·월 뉴스 표 (계획서 9절). 04의 뉴스 변수는 이 표에서 나온다 | `src/03_text_features.py` (기사가 있는 환경에서 돌리면 새로 저장) |
| `last_trading_days.csv` | 월별 마지막 거래일. 기사를 어느 달에 넣을지 정할 때 쓴다 | `src/make_trading_days.py` (한 번만) |
| `news_targets.csv` | 수집 기록 (선택) | B-1이 직접 적는다 |

## news_monthly.csv

| 열 | 내용 |
|---|---|
| `month`, `code` | 키. `YYYY-MM`, 6자리 종목코드 |
| `topic_tone` | 화제 논조: 그달 화제형 기사 점수 `s = P(긍정) − P(부정)`의 평균 |
| `n_topic` | 화제형 기사 수 (점검용, 모델에 넣지 않는다) |
| `no_news` | 화제형 기사가 없으면 1 |

이 표에 없는 종목·월은 결합할 때 `no_news = 1`이 된다.

## news_targets.csv (선택)

| 열 | 내용 |
|---|---|
| `code` | 6자리 종목코드 |
| `start_month`, `end_month` | 그 종목의 기사를 받은 기간. `YYYY-MM` |
| 그 밖의 열 | 자유 (수집 날짜, 검색어, 언론사, 받은 건수, 정제 후 건수 등) |

이 파일이 있으면 수집한 종목·월이 전부 `news_monthly.csv`의 행이 되어, "수집했지만 화제형 기사가 없는 칸"과 "수집하지 않은 칸"이 구분된다.
수집 기록에 없는 종목·월의 기사는 표에서 빠진다(실행할 때 뺀 칸 수를 출력한다). 파일이 없으면 화제형 기사가 있는 칸만 행이 된다.
UTF-8로 저장한다.
