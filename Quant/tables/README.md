## tp_monthly.csv

행 = 수집 대상(전년 12월 말 시총 상위 200, 배포 시총 기준) × 그해 1~12월. 그달 기사가 0건이어도 행이 있다.
기사를 받은 마지막 달까지만 행이 있다(그 뒤는 "수집 안 함").

| 열 | 내용 |
|---|---|
| `month`, `code` | 키. `YYYY-MM`, 6자리 종목코드 (문자열로 읽는다) |
| `news_missing` | 이 표에서는 모두 0 (수집 대상) |
| `tp_up` | 본 변수: 그달 목표가 상향 기사(제목 키워드 v0)가 있으면 1 |
| `n_tp_up` | 목표가 상향 기사 수 (참고) |
| `n_news` | 그달 그 종목 기사 수 (참고, 수집 점검용) |

합치는 규칙 (11/22 아영 결측 기준):
1. 정형 데이터에 `month`·`code`로 왼쪽 합치기 (정형 행은 그대로 두고 뉴스 칸만 붙인다)
2. 이 표에 없는 정형 행 = 수집 대상 밖 → `news_missing = 1`, `tp_up = 0`
3. 월은 추가로 밀지 않는다 (기사 월 = 그달 마지막 거래일 전날까지). 예측 대상은 다음 달 수익률(target)
4. v2의 `Month`는 `2002-04-01` 형식이라 앞 7자리(`2002-04`)로 바꿔서 합친다
