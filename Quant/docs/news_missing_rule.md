# 뉴스 변수 결측 처리 기준

작성: 정아영 (B-1) · 2026-11-23 · 근거 파일: `목표가상향_변수_합치기용.csv`, `목표가상향_변수_설명.md`

## 1. 목적
뉴스는 시가총액 상위 200 종목에만 모았다. "기사가 없었다"와 "수집하지 않았다"를 모델이 구분하도록 결측 처리 기준을 하나로 정한다. 이안·예원·영섭이 모두 같은 기준을 쓴다.

## 2. 변수
| 칸 | 뜻 |
|---|---|
| news_missing | 1 = 그해 뉴스 미수집(전년 말 시총 상위 200 밖), 0 = 수집 대상 |
| tp_up | 그달 목표가 상향 기사 있음 1 / 없음 0 (본 변수) |
| n_tp_up | 목표가 상향 기사 수 (참고) |
| n_news | 그달 그 회사 기사 수 전체 (참고) |

## 3. 처리 규칙
| 경우 | 값 | news_missing |
|---|---|---|
| 상위 200 종목, 그달 목표가 상향 기사 있음 | tp_up = 1, 건수 = 원래 값 | 0 |
| 상위 200 종목, 그달 기사 없음 (수집했는데 0건) | tp_up = 0, 건수 = 0 | 0 |
| 상위 200 밖 종목 (뉴스 수집 안 함) | tp_up = 0, 건수 = 0 | 1 |

- 합치는 법: 정형 데이터에 `month`·`code` 기준 왼쪽 합치기. 정형 행은 그대로 두고 뉴스 칸만 붙인다. 뉴스 파일에 없는 정형 행은 상위 200 밖으로 처리한다.
- 건수는 순위로 바꾸지 않고 원래 값 그대로 쓴다.
- 논조(긍정·부정 점수)는 쓰지 않는다.

## 4. 시점 규칙 (미래 정보 차단)
- 뉴스 대상 종목은 전년 12월 말 시가총액 상위 200으로 정한다.
- 기사는 그달 마지막 거래일 전 기사만 그달로 센다. 마지막 거래일 당일 이후 기사는 다음 달로 보낸다.
- 뉴스 월을 추가로 밀지 않는다. 예측 대상은 다음 달 수익률(target)이다.
- 평균 같은 통계가 필요하면 train(2001–2021) 기간 안에서만 계산한다.

## 5. 이렇게 정한 이유
- 상위 200 밖을 0으로만 채우면 "기사 없음"과 구분되지 않아, 값에 의미가 생긴다(중립값 채움 지적). 그래서 `news_missing` 표시 변수를 따로 둔다.
- 전년 말 시총 기준으로 수집 대상을 정하면 그해 기사 유무로 대상이 정해지는 미래 정보 문제를 피한다.

## 6. 2022~2025년 적용
- 같은 규칙을 쓴다. 대상은 전년 12월 말 시총 상위 200, 기사 정리·키워드·월 귀속은 2001~2021과 동일하게 한다.
- 2022년 이후 수익률은 기사 처리에 쓰지 않는다.

## 7. 한계
- 뉴스가 상위 200에만 있어 중소형주는 `news_missing = 1`로 처리된다.
- 키워드 정밀도만 확인했고, 키워드가 놓친 기사 비율(재현율)은 측정하지 못했다.
